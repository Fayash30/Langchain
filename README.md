# LangChain Learning Journey

A hands-on repository documenting my journey into **LangChain, LLM application development, and Agentic AI** through practical implementations, experiments, and code.

The goal is to understand how to build real-world applications powered by Large Language Models (LLMs), moving from foundational concepts to advanced AI workflows.

## 📚 Learning Modules

### LangChain Fundamentals

Exploring the core components of LangChain and learning how to interact with different LLM providers.

**Topics Covered:**
- Initializing chat models using LangChain
- Integrating Google Gemini, OpenAi and Groq
- Using `init_chat_model()` for provider-independent model initialization
- Understanding model invocation and response objects
- Configuring API keys using environment variables
- Working with different LLM providers
- Managing dependencies and Python environments using UV

**Key Implementations:**
- Google Gemini integration
- Groq integration
- OpenAI-compatible model interfaces
- Experimenting with different chat models
